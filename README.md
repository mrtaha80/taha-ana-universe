# جهانِ کوچکِ طاها و آنا

وب‌اپِ دونفره‌ی فارسی، راست‌چین و واکنش‌گرا برای آنا؛ از **۸ آگوست ۲۰۲۶**. خطِ زمان، خاطره‌ها، آرزوهای مشترک، ملودیِ آرامِ اورجینال، و پلیری که آهنگِ انتخابی‌تون را فقط همان لحظه از دستگاه پخش می‌کند.

## لینکِ عمومیِ رایگان

نشانیِ GitHub Pages: `https://mrtaha80.github.io/taha-ana-universe/`. برای بارِ اول، مالک repo در GitHub به **Settings → Pages** برود، در «Build and deployment» گزینه‌ی **Deploy from a branch** را انتخاب کند و `main` + `/(root)` را ذخیره کند. بعد از آماده‌شدن Pages، همین نشانی باز می‌شود؛ فایل QR همین نشانی را باز می‌کند. کد منبع و فایل‌های سایت داخل همین repo هستند.

## آهنگ

آهنگِ دارای حق نشر را به repo اضافه نکرده‌ام. «ملودیِ آرومِ سایت» صدای سینوسیِ ساخته‌شده در خود مرورگر است. برای آهنگ خودتان «بارگذاریِ آهنگِ خودتون» را بزنید؛ فایل فقط همان نشست روی دستگاه پخش می‌شود؛ autoplay، آپلود به سرور یا ذخیره در مرورگر ندارد. فقط آهنگی را انتخاب کنید که اجازه‌ی پخشش را دارید.

## ذخیره‌ی ابری

**دیتابیس هنوز فعال نیست.** خاطره و mood فعلاً در `localStorage` همان مرورگر می‌مانند و با آنا sync نمی‌شوند. `sql/supabase-starter.sql` طرحِ پایه‌ی جدول مشترک با RLS برای یک پروژه‌ی Supabase است، نه دیتابیس زنده و نه کدی که سایت الآن مصرف کند. برای راه‌اندازی، در یک پروژه‌ی Supabase رایگان فقط دو حساب بسازید، UUID همان دو حساب را در انتهای SQL allowlist کنید، SQL را اجرا و RLS را تست کنید. اتصال اپ به سرویس به URL و کلید عمومی پروژه‌ی خودتان و پیاده‌سازیِ اتصال نیاز دارد. هیچ رمز یا service-role key را داخل repo یا فرانت‌اند قرار ندهید.

نامه‌های تاریخ‌دار روی همین دستگاه می‌مانند؛ قفلشان نمایشی است، نه رمزنگاری‌شده. هوا و نقشه نمایشی هستند و مکان‌یابی ندارند.
